Conceito Bootstrap & UX

O Bootstrap é um framework front-end amplamente utilizado para acelerar e padronizar o desenvolvimento de interfaces responsivas. Ele já traz prontos componentes como modais, alertas, botões, formulários e um sistema de grid, o que evita escrever todo o CSS do zero.

Neste projeto V5, criamos à mão componentes inspirados nele (modais limpos, feedbacks não-bloqueantes e tipografia consistente) para substituir os diálogos nativos alert e confirm. Com o Bootstrap, bastaria usar as classes modal e alert alert-danger para chegar ao mesmo resultado em muito menos tempo, garantindo uma experiência de usuário (UX) profissional e integrada ao design roxo estilizado.
